# imiracles.co.in

Website for I-miracles by Diviya S Chachra. A static site served by GitHub Pages.

- `index.html`: the whole site (styles and script are inline)
- `img/`: photos
- `CNAME`: tells GitHub Pages the custom domain

## Settings inside index.html (near the bottom, in the <script>)
- `WA`: WhatsApp number with country code, digits only
- `DIVYA_EMAIL`: the calendar that receives booking invites
- `APPOINTMENT_URL`: paste the Google Calendar Appointment schedule link here to show live slots
- `SESSIONS` / `CLASSES`: names, descriptions, prices
